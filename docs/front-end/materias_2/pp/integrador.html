Trazabilidad entre el Workspace y las Clases

1. Instanciación Compuesta

En el Workspace ejecutamos netflix := Plataforma crearPlataforma:.... El método de clase ejecuta ^(super new) initPlataforma:..., creando la instancia e inicializando contenidos := OrderedCollection new.

2. Herencia con super

Al instanciar con crearPeli:... o crearSerie:..., su método init envía super initCont:... para cargar los 7 atributos heredados en Contenido y luego asigna sus 2 atributos propios.

3. Agregación y Validación

Con netflix agregarContenido: peli1, el objeto netflix calcula self espacioOcupado + unCont verTamanio y valida que no supere capacidad antes de ejecutar contenidos add: unCont.

Punto 1. Listado de contenidos con calificación >= 7 (select: + do:) 
(opc = '1. Listado calificación >= 7') ifTrue: [
    Transcript show: '--- CALIFICACION >= 7 ---'; cr.
    colFil := netflix verContenidos select: [:c | c verCalificacion >= 7].
    colFil do: [:c | 
        Transcript show: c verTitulo, ' (', c verCalificacion displayString, ')'; cr
    ].
    Transcript cr.
].

Relación Clases ↔ Workspace: Se solicita la colección al objeto netflix con Plataforma >> verContenidos. El iterador select: evalúa el bloque enviando el mensaje heredado Contenido >> verCalificacion a cada instancia y retorna una nueva colección con los 9 contenidos que cumplen la condición (excluyendo a Zoolander con 6.5).

Punto 2. Filtrar el catálogo por género (Prompter + select:) 
(opc = '2. Filtrar por género') ifTrue: [
    | gen |
    gen := Prompter prompt: 'Ingrese género a buscar:'.
    Transcript show: '--- GÉNERO: ', gen, ' ---'; cr.
    colFil := netflix verContenidos select: [:c | c verGenero = gen].
    colFil do: [:c | Transcript show: c verTitulo; cr].
    Transcript cr.
].

Relación Clases ↔ Workspace: La clase Prompter captura el String ingresado por el usuario y lo guarda en la variable temporal gen. Luego select: compara ese valor con el retorno de Contenido >> verGenero en cada objeto.

Punto 3. Contenidos recomendables para maratón (Polimorfismo y Binding Dinámico) 
(opc = '3. Listado recomendables para maratón') ifTrue: [
    Transcript show: '--- RECOMENDADOS PARA MARATÓN ---'; cr.
    colFil := netflix verContenidos select: [:c | c esRecomendable].
    colFil do: [:c | Transcript show: c verTitulo; cr].
    Transcript cr.
].

Polimorfismo y Binding Dinámico: En Contenido el método esRecomendable está declarado como ^self subclassResponsibility. En tiempo de ejecución, si c es instancia de Pelicula ejecuta ^(duracion <= 120) & (self verCalificacion >= 7); si es instancia de Serie ejecuta ^finalizada & (temporadas <= 3) & (self verCalificacion >= 7).

Punto 4. Tamaño promedio y contenidos que lo superan (size + do: + select:) 
(opc = '4. Tamaño promedio y superiores') ifTrue: [
    | suma cant |
    suma := 0.
    cant := netflix verContenidos size.
    (cant > 0) ifTrue: [
        netflix verContenidos do: [:c | suma := suma + c verTamanio].
        prom := suma / cant.
        Transcript show: 'Promedio general: ', prom displayString, ' MB'; cr.
        colFil := netflix verContenidos select: [:c | c verTamanio > prom].
        colFil do: [:c | Transcript show: '- ', c verTitulo, ' (', c verTamanio displayString, ' MB)'; cr].
    ].
].

Relación Clases ↔ Workspace: Primero recorre todos los objetos con do: enviando el mensaje Contenido >> verTamanio para acumular el total (81.500 MB / 10 = 8.150 MB de promedio) y luego filtra con select: los 4 objetos cuyo tamaño supera ese promedio.

Punto 5. Contenido con mayor calificación (first + do:) 
(opc = '5. Contenido con mayor calificación') ifTrue: [
    netflix verContenidos isEmpty ifFalse: [
        mejor := netflix verContenidos first.
        netflix verContenidos do: [:c |
            (c verCalificacion > mejor verCalificacion) ifTrue: [ mejor := c ].
        ].
        Transcript show: mejor verTitulo, ' con ', mejor verCalificacion displayString, ' puntos.'; cr.
    ].
].

Relación Clases ↔ Workspace: Toma como referencia inicial el primer objeto de la colección mediante first y recorre con do: comparando las calificaciones mediante verCalificacion hasta hallar a Breaking Bad (9.5 puntos).

Punto 6. Eliminar contenidos NO disponibles (select: not + modContenidos:) 
(opc = '6. Eliminar NO disponibles') ifTrue: [
    | eliminados |
    eliminados := netflix verContenidos select: [:c | c verDisponible not].
    eliminados isEmpty ifTrue: [
        MessageBox notify: 'Todos los contenidos están disponibles actualmente.'.
    ] ifFalse: [
        eliminados do: [:c | Transcript show: '- ', c verTitulo; cr].
        netflix modContenidos: (netflix verContenidos select: [:c | c verDisponible]).
        MessageBox notify: 'Se eliminaron los contenidos listados en el Transcript.'.
    ].
].

Modificación de Estado en Plataforma: Identifica los objetos con disponible = false (El Conjuro y Dark) enviando el mensaje unario not al booleano retornado por verDisponible. Luego actualiza la variable de instancia contenidos de netflix usando Plataforma >> modContenidos:.

Punto 7. Cantidad de contenidos por género (Dictionary + collect: + asSet) 
(opc = '7. Cantidad por género (Diccionario)') ifTrue: [
    dic := Dictionary new.
    colGen := netflix verContenidos collect: [:c | c verGenero].
    sinRep := colGen asSet.
    sinRep do: [:g | dic at: g put: (colGen occurrencesOf: g)].
    dic keysDo: [:k |
        Transcript show: 'Género: ', k, ' - Cantidad: ', (dic at: k) displayString; cr.
    ].
].

Transformación y Diccionario: collect: genera una colección integrada únicamente por los Strings de los géneros (colGen). Con asSet eliminamos las repeticiones y con occurrencesOf: contabilizamos cuántas veces aparece cada género para guardarlo como par clave -> valor en el Dictionary.

Punto 8. Agregar nuevo contenido validando capacidad (agregarContenido:) 
(opc = '8. Agregar nuevo contenido') ifTrue: [
    espacioLibre := netflix verCapacidad - netflix espacioOcupado.
    MessageBox notify: 'Espacio disponible en la plataforma: ', espacioLibre displayString, ' MB.'.
    "... Ingreso de datos con ChoicePrompter, Prompter y MessageBox confirm: ..."
    nuevoObj := Pelicula crearPeli:cod tit:tit gen:gen anio:anio tam:tam calif:calif disp:disp dur:dur cine:cine.
    netflix agregarContenido: nuevoObj.
].

Delegación de Responsabilidad: El Workspace instancia el nuevo objeto y se lo envía a netflix agregarContenido: nuevoObj. Es la propia clase Plataforma la que verifica internamente ((self espacioOcupado + unCont verTamanio) <= capacidad) antes de agregarlo o mostrar un MessageBox errorMsg:.

Punto 9. Buscar y modificar contenido por código (detect: ifNone: + setters) 
(opc = '9. Buscar y modificar por código') ifTrue: [
    codBuscado := (Prompter prompt: 'Ingrese el código a modificar:') asNumber.
    encontrado := netflix verContenidos detect: [:c | c verCodigo = codBuscado] ifNone: [nil].
    (encontrado isNil) ifTrue: [
        MessageBox warning: 'No se encontró ningún contenido con ese código.'.
    ] ifFalse: [
        encontrado modTitulo: nuevoTit.
        encontrado modCalificacion: nuevaCal.
    ].
].

Búsqueda Única y Mutación por Referencia: detect:ifNone: retorna la referencia directa a la instancia buscada (o nil si no existe). Al enviarle modTitulo: y modCalificacion:, modificamos el estado interno de ese objeto directamente en la colección de netflix.

Punto 10. Eliminar un contenido por código (reject: + modContenidos:) 
(opc = '10. Eliminar contenido por código') ifTrue: [
    | codEliminar |
    codEliminar := (Prompter prompt: 'Ingrese el código a eliminar:') asNumber.
    netflix modContenidos: (netflix verContenidos reject: [:c | c verCodigo = codEliminar]).
    MessageBox notify: 'Actualización finalizada (Si el código existía, fue eliminado).'.
].

Iterador reject: A diferencia de select:, el iterador reject: incluye en la nueva colección únicamente los elementos donde el bloque evalúa en false, descartando el objeto cuyo código coincide con codEliminar.
