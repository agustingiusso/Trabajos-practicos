2. Implementación del Menú

El menú interactivo se mantiene en ejecución mediante un bucle whileTrue: y utiliza la clase ChoicePrompter.

Estructura de repetición y Prompter 
continuar := true.
[continuar] whileTrue: [
    opc := ChoicePrompter choices: #(
        '1. Listado calificación >= 7'
        '2. Filtrar por género'
        '3. Listado recomendables para maratón'
        '8. Agregar nuevo contenido'
        '0. Salir'
    ).
    
    (opc isNil) ifTrue: [ continuar := false ] ifFalse: [
        "Resolución de opciones..."
        (opc = '0. Salir') ifTrue: [ continuar := false ].
    ].
].

3. Simulador de Memoria e Iteradores

Visualización en tiempo real de cómo los iteradores de colección (select:, collect:, reject:) procesan los objetos en la RAM, y cómo actúa el Binding Dinámico.

A. Filtrado (select:) 
colFil := netflix verContenidos select: [:c | 
    c verCalificacion >= 7
].

Retorna una nueva colección solo con los elementos que cumplen la condición booleana.

B. Transformación (collect:) 
colGen := netflix verContenidos collect: [:c | 
    c verGenero
].

Retorna una nueva colección mapeando los objetos a un nuevo tipo de dato (Strings).

C. Eliminación (reject:) 
eliminados := netflix verContenidos reject: [:c | 
    c verDisponible
].

Retorna una nueva colección excluyendo los elementos que devuelven true.

D. Polimorfismo (esRecomendable) 
colFil := netflix verContenidos select: [:c | 
    c esRecomendable
].

El mensaje es único, pero el Binding Dinámico decide qué regla aplicar según si es Serie o Película.
