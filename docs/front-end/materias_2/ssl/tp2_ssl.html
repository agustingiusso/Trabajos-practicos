Ejercicio 1

a) Especificar el TAD Concesionaria, donde Auto es el TAD definido en el TP 1.

b) Realizar una aplicación que permita crear una concesionaria, le cargue varios autos e imprima la patente de los autos cuyo precio oscile entre los $16.000.000 y $20.000.000.

Resolución:

a) Especificación del TAD Concesionaria:

  • crearConcesionaria(): retorna una concesionaria vacía.
  • agregarAuto(c, auto): añade un TAD Auto a la concesionaria.
  • obtenerAutos(c): retorna la lista de autos.

b) Programa de aplicación:

# Asumimos que existen las operaciones del TAD Auto (TP1)
concesionaria = crearConcesionaria()
continuar = "s"

while continuar.lower() == "s":
    auto = crearAuto()
    pat = input("Patente: ")
    km = int(input("Kilometraje: "))
    mar = input("Marca: ")
    mod = input("Modelo: ")
    prec = float(input("Precio: "))
    
    cargarAuto(auto, pat, km, mar, mod, prec)
    agregarAuto(concesionaria, auto)
    
    continuar = input("¿Cargar otro auto? (s/n): ")

print("\n--- Autos con precio entre $16M y $20M ---")
lista_autos = obtenerAutos(concesionaria)
for a in lista_autos:
    precio = verPrecio(a)
    if 16000000 <= precio <= 20000000:
        print(f"Patente: {verPatente(a)} - Precio: ${precio}")

Ejercicio 2

a) Especificar el TAD Biblioteca, utilizando el TAD Libro del TP 1.

b) Imprimir el nombre y el autor de todos los libros de género ensayo.

c) Cambiar a género "Novela" el libro de código 1203.

Resolución:

a) Especificación del TAD Biblioteca:

  • crearBiblioteca(): retorna una biblioteca vacía.
  • agregarLibro(b, libro): añade un TAD Libro a la biblioteca.
  • obtenerLibros(b): retorna la colección de libros.

b y c) Programa de aplicación:

# Asumimos una biblioteca 'mi_biblio' ya cargada con libros
libros = obtenerLibros(mi_biblio)

print("--- Libros de género Ensayo ---")
for libro in libros:
    # Punto B: Imprimir nombre y autor de ensayos
    if verGenero(libro).lower() == "ensayo":
        print(f"Nombre: {verNombre(libro)} | Autor: {verAutor(libro)}")
        
    # Punto C: Cambiar a Novela el código 1203
    if verCodigo(libro) == 1203:
        modGenero(libro, "Novela")
        print(f"\nSe actualizó el género del libro código 1203 a Novela.")

Ejercicio 4

a) Especificar el TAD pila de libros, utilizando el TAD Libro del TP 1.

b) En una aplicación simular la devolución de libros en una sala de lectura donde se apilan para luego ser acomodados en su lugar. Imprimir al finalizar la cantidad total de libros devueltos.

c) Pasar a otra pila los libros de la editorial Mc Graw Hill devueltos.

Resolución:

# a) TAD Pila: crearPila(), apilar(p, elem), desapilar(p), pilaVacia(p)
pila_devoluciones = crearPila()
total_devueltos = 0

# b) Simular devoluciones
continuar = "s"
while continuar.lower() == "s":
    l = crearLibro()
    # Se omiten inputs para cargarLibro por brevedad
    cargarLibro(l, 10, "Ejemplo", "Autor", "Genero", input("Editorial: "), 1000)
    apilar(pila_devoluciones, l)
    total_devueltos += 1
    continuar = input("¿Ingresar devolución? (s/n): ")

print(f"\nCantidad total de libros devueltos: {total_devueltos}")

# c) Pasar a otra pila los de Mc Graw Hill
pila_mcgraw = crearPila()
pila_auxiliar = crearPila()

while not pilaVacia(pila_devoluciones):
    libro_actual = desapilar(pila_devoluciones)
    
    if verEditorial(libro_actual).lower() == "mc graw hill":
        apilar(pila_mcgraw, libro_actual)
    else:
        apilar(pila_auxiliar, libro_actual)

# (Opcional) Restaurar la pila original con los libros que no son McGraw Hill
while not pilaVacia(pila_auxiliar):
    apilar(pila_devoluciones, desapilar(pila_auxiliar))

Ejercicio 5

a) Especificar el TAD Cliente y b) TAD Cola de clientes.

c) Simular la llegada de clientes a un Rapi Pago entre las 10 y las 17hs. Si la caja está ocupada, el cliente va a la cola. Ingresar por teclado el estado de la caja. Imprimir al final de cada hora el porcentaje de clientes atendidos directamente y al final del día el total.

Resolución:

# TAD Cola: crearCola(), encolar(c, elem), desencolar(c), colaVacia(c)
cola_clientes = crearCola()
total_dia = 0

for hora in range(10, 17): # De 10 a 16 inclusive (hasta las 17hs)
    llegadas_hora = int(input(f"\nClientes que llegaron a las {hora}hs: "))
    atendidos_directo = 0
    
    for _ in range(llegadas_hora):
        c = crearCliente() # Instancia TAD Cliente
        estado_caja = input("¿Caja libre? (s/n): ")
        
        if estado_caja.lower() == 's':
            # Atendido directamente
            atendidos_directo += 1
            total_dia += 1
        else:
            # Pasa a la cola
            encolar(cola_clientes, c)
            
    # Atender a alguien de la cola si se liberó la caja en el medio
    if not colaVacia(cola_clientes) and input("¿Se liberó caja para la cola? (s/n): ") == 's':
        desencolar(cola_clientes)
        total_dia += 1

    # Cálculos por hora
    if llegadas_hora > 0:
        porcentaje = (atendidos_directo * 100) / llegadas_hora
        print(f"--- Fin de las {hora}hs ---")
        print(f"Porcentaje atendidos directamente: {porcentaje:.2f}%")
    else:
        print("No llegaron clientes esta hora.")

print(f"\n=== FIN DEL DÍA ===")
print(f"Total de clientes atendidos hoy: {total_dia}")
