Ejercicio 1

Suponer ya creado y guardado en el ambiente Python el TAD Medicamento que sirve para almacenar el nombre genérico, nombre comercial, laboratorio y precio de un remedio. Acepta las siguientes operaciones:

  • crearMed()
  • cargarMed(r, nomg, nomcom, lab, prec)
  • verNomGen(r), verNomCom(r), verLab(r), verPrecio(r)
  • modNomGen(r, otroNG), modNomCom(r, otroNC), modLab(r, otroL), modPrecio(r, otroP)
  • copiar(r1, r2)

a) Hacer un programa de aplicación que permita crear 2 remedios e imprima el nombre comercial del remedio más caro, utilizando para manipular las variables de tipo TAD solamente las operaciones especificadas.

Resolución:

# Programa de aplicación
r1 = crearMed()
r2 = crearMed()

cargarMed(r1, "Ibuprofeno", "Ibupirac", "Pfizer", 1500.50)
cargarMed(r2, "Paracetamol", "Tafirol", "Genomma", 1200.00)

Ejercicio 2

Suponer ya creado el TAD Trámite que permite almacenar tipo de trámite, nro cliente, dni cliente, día y mes de ingreso. Operaciones: crearTram(), cargarTram(), sus getters (verTipo(), etc.), setters y copiar().

a) Hacer un programa de aplicación que simule la recepción de varios trámites (usar un while) y los cargue en una lista. Luego imprima la cantidad de solicitudes de cambio de titularidad recibidas y un listado con el tipo de trámite y el nro de cliente de todos aquellos trámites que fueron realizados entre el 10 y el 25 de marzo.

Resolución:

tramites = []
continuar = input("¿Desea ingresar un trámite? (s/n): ")

while continuar.lower() == 's':
    t = crearTram()
    tipo = input("Tipo (reclamo/alta/baja/cambio titular): ")
    nro_c = int(input("Nro Cliente: "))
    dni = input("DNI: ")
    dia = int(input("Día: "))
    mes = int(input("Mes: "))
    
    cargarTram(t, tipo, nro_c, dni, dia, mes)
    tramites.append(t)
    
    continuar = input("¿Desea ingresar otro trámite? (s/n): ")

cambios_titularidad = 0
print("\n--- Trámites realizados entre el 10 y el 25 de marzo ---")

for t in tramites:
    # Contar cambios de titularidad
    if verTipo(t) == "cambio de titular del servicio":
        cambios_titularidad += 1
        
    # Filtrar por fechas
    if verMes(t) == 3 and 10 <= verDia(t) <= 25:
        print(f"Tipo: {verTipo(t)} - Nro Cliente: {verNroC(t)}")

print(f"\nTotal solicitudes cambio de titularidad: {cambios_titularidad}")

  • cargarLibro(l, cod, nom, aut, gen, edi, prec)
  • verCodigo(l), verNombre(l), verAutor(l), verGenero(l), verEditorial(l), verPrecio(l)

l1 = crearLibro()
l2 = crearLibro()

cargarLibro(l1, 101, "Matemática 1", "Pérez", "Educativo", "Santillana", 10000)
cargarLibro(l2, 102, "Física Básica", "Gómez", "Educativo", "Kapelusz", 12000)

Ejercicio 5

Defina la estructura interna del TAD Auto e implemente cada una de las operaciones especificadas.

Resolución:

Estructura interna elegida: Lista de Python [patente, kilometraje, marca, modelo, precio].

def crearAuto():
    return ["", 0, "", "", 0.0]

def cargarAuto(a, pat, km, mar, mod, prec):
    a[0] = pat
    a[1] = km
    a[2] = mar
    a[3] = mod
    a[4] = prec

# Getters
def verPatente(a): return a[0]
def verKilometraje(a): return a[1]
def verMarca(a): return a[2]
def verModelo(a): return a[3]
def verPrecio(a): return a[4]

# Setters
def modPatente(a, pat): a[0] = pat
def modKilometraje(a, km): a[1] = km
def modMarca(a, mar): a[2] = mar
def modModelo(a, mod): a[3] = mod
def modPrecio(a, prec): a[4] = prec

Ejercicio 6

Defina la estructura interna del TAD Libro e implemente cada una de las operaciones especificadas.

Resolución:

Estructura interna elegida: Lista de Python [código, nombre, autor, género, editorial, precio].

def crearLibro():
    return [0, "", "", "", "", 0.0]

def cargarLibro(l, cod, nom, aut, gen, edi, prec):
    l[0] = cod
    l[1] = nom
    l[2] = aut
    l[3] = gen
    l[4] = edi
    l[5] = prec

# Getters
def verCodigo(l): return l[0]
def verNombre(l): return l[1]
def verAutor(l): return l[2]
def verGenero(l): return l[3]
def verEditorial(l): return l[4]
def verPrecio(l): return l[5]

# Setters
def modCodigo(l, cod): l[0] = cod
def modNombre(l, nom): l[1] = nom
def modAutor(l, aut): l[2] = aut
def modGenero(l, gen): l[3] = gen
def modEditorial(l, edi): l[4] = edi
def modPrecio(l, prec): l[5] = prec
