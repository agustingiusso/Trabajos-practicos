Ejercicio 1

Calcular por definición la transformada de Laplace de las siguientes funciones:

  • 1.1) $f(t) = \begin{cases} 0, & t < 0 \\ 3, & t \ge 0 \end{cases}$
  • 1.2) $f(t) = \begin{cases} 0, & t < 0 \\ 3e^{-2t}, & t \ge 0 \end{cases}$

Resolución Analítica (Definición: $F(s) = \int_0^\infty f(t)e^{-st}dt$):

1.1) Constante f(t) = 3

$$ \mathcal{L}\{3\} = \int_{0}^{\infty} 3 e^{-st} dt = 3 \lim_{b \to \infty} \int_{0}^{b} e^{-st} dt $$

Resolvemos la integral:

$$ = 3 \lim_{b \to \infty} \left[ \frac{e^{-st}}{-s} \right]_{0}^{b} = -\frac{3}{s} \lim_{b \to \infty} \left( e^{-sb} - e^{0} \right) $$

Asumiendo que $Re(s) > 0$, $e^{-sb} \to 0$ cuando $b \to \infty$:

$$ = -\frac{3}{s} (0 - 1) = \mathbf{\frac{3}{s}} $$

1.2) Exponencial $f(t) = 3e^{-2t}$

$$ \mathcal{L}\{3e^{-2t}\} = \int_{0}^{\infty} 3e^{-2t} e^{-st} dt = 3 \lim_{b \to \infty} \int_{0}^{b} e^{-(s+2)t} dt $$

Resolvemos la integral:

$$ = 3 \lim_{b \to \infty} \left[ \frac{e^{-(s+2)t}}{-(s+2)} \right]_{0}^{b} = -\frac{3}{s+2} \lim_{b \to \infty} \left( e^{-(s+2)b} - 1 \right) $$

Asumiendo $Re(s) > -2$, el término con $b$ se hace cero:

$$ = -\frac{3}{s+2} (0 - 1) = \mathbf{\frac{3}{s+2}} $$

Ejercicio 2

Calcular $\lim_{t \to 0} f(t)$ y $\lim_{t \to \infty} f(t)$ para las siguientes funciones, utilizando los Teoremas de Valor Inicial y de Valor Final:

  • 2.1) $F(s) = \frac{1}{s(s+5)}$
  • 2.2) $F(s) = \frac{s}{(s-2)(s+3)}$
  • 2.3) $F(s) = \frac{1}{(s+5)}$

Resolución:

  • 2.1) $F(s) = \frac{1}{s(s+5)}$
    - Valor Inicial: $f(0^+) = \lim_{s \to \infty} s \cdot \frac{1}{s(s+5)} = \lim_{s \to \infty} \frac{1}{s+5} = \mathbf{0}$.
    - Valor Final: (Verificamos polos: $s=0, s=-5$. Como los polos distintos de cero tienen parte real negativa, aplica el TVF).
    $f(\infty) = \lim_{s \to 0} s \cdot \frac{1}{s(s+5)} = \lim_{s \to 0} \frac{1}{s+5} = \mathbf{\frac{1}{5}}$.
  • 2.2) $F(s) = \frac{s}{(s-2)(s+3)}$
    - Valor Inicial: $f(0^+) = \lim_{s \to \infty} s \cdot \frac{s}{(s-2)(s+3)} = \lim_{s \to \infty} \frac{s^2}{s^2+s-6} = \mathbf{1}$.
    - Valor Final: Polos en $s=2$ y $s=-3$. Existe un polo con parte real positiva ($s=2$). El sistema es inestable y no tiende a un estado estacionario, por lo que el Teorema de Valor Final no es aplicable (diverge).
  • 2.3) $F(s) = \frac{1}{s+5}$
    - Valor Inicial: $f(0^+) = \lim_{s \to \infty} s \cdot \frac{1}{s+5} = \lim_{s \to \infty} \frac{s}{s+5} = \mathbf{1}$.
    - Valor Final: (Polo en $s=-5$, aplicable).
    $f(\infty) = \lim_{s \to 0} s \cdot \frac{1}{s+5} = \frac{0}{5} = \mathbf{0}$.

Ejercicio 3

A partir de las tablas y propiedades, calcular la Transformada de Laplace de las siguientes funciones:

  • 3.1) $f(t) = 3t + 4$
  • 3.2) $f(t) = t^2 + 3t + 4$
  • 3.3) $f(t) = 2t e^t$
  • 3.4) $f(t) = e^{2t+4}$
  • 3.5) $f(t) = sen\left(\frac{\pi i}{2}\right)$

Resolución:

  • 3.1) Usamos la propiedad de Linealidad y la tabla: $\mathcal{L}\{t^n\} = \frac{n!}{s^{n+1}}$, $\mathcal{L}\{1\} = \frac{1}{s}$.
    $F(s) = 3\mathcal{L}\{t\} + 4\mathcal{L}\{1\} = 3\left(\frac{1}{s^2}\right) + 4\left(\frac{1}{s}\right) = \mathbf{\frac{3}{s^2} + \frac{4}{s}}$.
  • 3.2) Por Linealidad: $\mathcal{L}\{t^2\} = \frac{2}{s^3}$.
    $F(s) = \mathcal{L}\{t^2\} + 3\mathcal{L}\{t\} + 4\mathcal{L}\{1\} = \mathbf{\frac{2}{s^3} + \frac{3}{s^2} + \frac{4}{s}}$.
  • 3.3) Por el Primer Teorema de Traslación: $\mathcal{L}\{e^{at}f(t)\} = F(s-a)$. Sabiendo que $\mathcal{L}\{2t\} = \frac{2}{s^2}$, evaluamos en $(s-1)$.
    $F(s) = \mathbf{\frac{2}{(s-1)^2}}$.
  • 3.4) Aplicamos propiedades de potencias: $e^{2t+4} = e^4 \cdot e^{2t}$. Aquí $e^4$ opera como constante multiplicativa.
    $F(s) = e^4 \cdot \mathcal{L}\{e^{2t}\} = e^4 \left( \frac{1}{s-2} \right) = \mathbf{\frac{e^4}{s-2}}$.
  • 3.5) (Nota: asumiendo que el enunciado se refiere a la variable temporal $t$ en lugar de $i$) $\mathcal{L}\{\sin(kt)\} = \frac{k}{s^2+k^2}$ con $k = \pi/2$.
    $F(s) = \frac{\pi/2}{s^2 + (\pi/2)^2} = \mathbf{\frac{\pi/2}{s^2 + \pi^2/4}} = \mathbf{\frac{2\pi}{4s^2 + \pi^2}}$.

Ejercicio 4

Calcular la transformada de Laplace $Y(s)$ de las siguientes ecuaciones diferenciales:

  • 4.1) $\ddot{y} + 3\dot{y} + 6y = 0 \quad [y(0)=0, \dot{y}(0)=3]$
  • 4.2) $2\ddot{y} + 7\dot{y} + 3y = 0 \quad [y(0)=3, \dot{y}(0)=0]$
  • 4.3) $\ddot{y} - 3\dot{y} + 2y = 2e^{3t} \quad [y(0)=0, \dot{y}(0)=4]$
  • 4.4) $\ddot{y} + 5\dot{y} + 4y = t \quad [y(0)=0, \dot{y}(0)=1]$
  • 4.5) $\ddot{y} + 5\dot{y} + 4y = sen(t) \quad [y(0)=0, \dot{y}(0)=0]$

Resolución:

Recordatorio: $\mathcal{L}\{\ddot{y}\} = s^2Y(s) - sy(0) - \dot{y}(0)$ y $\mathcal{L}\{\dot{y}\} = sY(s) - y(0)$.

  • 4.1) $[s^2Y(s) - s(0) - 3] + 3[sY(s) - 0] + 6Y(s) = 0$
    $Y(s)(s^2 + 3s + 6) - 3 = 0 \implies \mathbf{Y(s) = \frac{3}{s^2 + 3s + 6}}$
  • 4.2) $2[s^2Y(s) - s(3) - 0] + 7[sY(s) - 3] + 3Y(s) = 0$
    $Y(s)(2s^2 + 7s + 3) - 6s - 21 = 0 \implies \mathbf{Y(s) = \frac{6s + 21}{2s^2 + 7s + 3}}$
  • 4.3) $[s^2Y(s) - s(0) - 4] - 3[sY(s) - 0] + 2Y(s) = \frac{2}{s-3}$
    $Y(s)(s^2 - 3s + 2) - 4 = \frac{2}{s-3} \implies Y(s)(s^2 - 3s + 2) = \frac{2}{s-3} + 4$
    $\mathbf{Y(s) = \frac{2}{(s-3)(s^2 - 3s + 2)} + \frac{4}{s^2 - 3s + 2}}$
  • 4.4) $[s^2Y(s) - s(0) - 1] + 5[sY(s) - 0] + 4Y(s) = \frac{1}{s^2}$
    $Y(s)(s^2 + 5s + 4) - 1 = \frac{1}{s^2} \implies Y(s)(s^2 + 5s + 4) = \frac{1}{s^2} + 1$
    $\mathbf{Y(s) = \frac{1}{s^2(s^2 + 5s + 4)} + \frac{1}{s^2 + 5s + 4}}$
  • 4.5) $[s^2Y(s) - 0 - 0] + 5[sY(s) - 0] + 4Y(s) = \frac{1}{s^2+1}$
    $Y(s)(s^2 + 5s + 4) = \frac{1}{s^2+1}$
    $\mathbf{Y(s) = \frac{1}{(s^2+1)(s^2 + 5s + 4)}}$

Ejercicio 5

Calcular la transformada inversa de Laplace $y(t)$ de las siguientes funciones:

  • 5.1) $Y(s) = \frac{1}{s(s+5)}$
  • 5.2) $Y(s) = \frac{s}{(s-2)(s+3)}$
  • 5.3) $Y(s) = \frac{1}{(s+5)}$
  • 5.4) $Y(s) = \frac{s+3}{(s^2+s-2)}$
  • 5.5) $Y(s) = \frac{s}{s^2-1} + \frac{s-2}{(s^2+s)}$

Resolución:

  • 5.1) $Y(s) = \frac{1}{s(s+5)}$
    Fracciones parciales: $\frac{A}{s} + \frac{B}{s+5} = \frac{1}{s(s+5)} \implies A(s+5) + Bs = 1$
    Si $s=0 \implies 5A = 1 \implies A = 1/5$. Si $s=-5 \implies -5B = 1 \implies B = -1/5$.
    $y(t) = \mathcal{L}^{-1}\left\{\frac{1/5}{s} - \frac{1/5}{s+5}\right\} = \mathbf{\frac{1}{5} - \frac{1}{5}e^{-5t}}$.
  • 5.2) $Y(s) = \frac{s}{(s-2)(s+3)}$
    Fracciones parciales: $\frac{A}{s-2} + \frac{B}{s+3}$. $A = [\frac{s}{s+3}]_{s=2} = \frac{2}{5}$. $B = [\frac{s}{s-2}]_{s=-3} = \frac{-3}{-5} = \frac{3}{5}$.
    $y(t) = \mathcal{L}^{-1}\left\{\frac{2/5}{s-2} + \frac{3/5}{s+3}\right\} = \mathbf{\frac{2}{5}e^{2t} + \frac{3}{5}e^{-3t}}$.
  • 5.3) $Y(s) = \frac{1}{s+5}$
    Aplicación directa de tabla: $\mathcal{L}^{-1}\left\{\frac{1}{s-a}\right\} = e^{at}$.
    $y(t) = \mathbf{e^{-5t}}$.
  • 5.4) $Y(s) = \frac{s+3}{s^2+s-2}$
    Factorizando denominador: raíces de $s^2+s-2=0$ son $s=1, s=-2$. $\implies (s-1)(s+2)$.
    $\frac{A}{s-1} + \frac{B}{s+2}$. $A = [\frac{s+3}{s+2}]_{s=1} = \frac{4}{3}$. $B = [\frac{s+3}{s-1}]_{s=-2} = \frac{1}{-3} = -\frac{1}{3}$.
    $y(t) = \mathcal{L}^{-1}\left\{\frac{4/3}{s-1} - \frac{1/3}{s+2}\right\} = \mathbf{\frac{4}{3}e^t - \frac{1}{3}e^{-2t}}$.
  • 5.5) $Y(s) = \frac{s}{s^2-1} + \frac{s-2}{s^2+s}$
    Término 1: Directo de tabla $\mathbf{\cosh(t)}$ (o fracciones parciales $\frac{1/2}{s-1} + \frac{1/2}{s+1} = \frac{1}{2}e^t + \frac{1}{2}e^{-t}$).
    Término 2: Fracciones parciales de $\frac{s-2}{s(s+1)} = \frac{A}{s} + \frac{B}{s+1}$. $A = [\frac{s-2}{s+1}]_{s=0} = -2$. $B = [\frac{s-2}{s}]_{s=-1} = \frac{-3}{-1} = 3$.
    Antitransformada de Término 2: $-2 + 3e^{-t}$.
    Sumando todo: $y(t) = \cosh(t) - 2 + 3e^{-t}$ (o también $\mathbf{\frac{1}{2}e^t + \frac{7}{2}e^{-t} - 2}$).
