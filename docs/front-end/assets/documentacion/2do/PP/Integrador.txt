"--- BLOQUES VALIDADORES (EXPLICACIÓN PARA EL COLOQUIO) ---"
"Guardamos la lógica de validación en bloques [:mensaje | ...] para no repetir código.
Cada bloque usa un bucle 'whileFalse:' controlado por una variable booleana 'valido'.
Mientras el usuario ingrese datos nulos (isNil) o vacíos, el bloque lo frena con 'MessageBox warning:' y repite el pedido."

"1. Validador para Textos"
pedirTexto := [:mensaje |
    | input valido |
    valido := false.
    input := ''.
    [valido] whileFalse: [
        input := Prompter prompt: mensaje.
        (input isNil) ifTrue: [
            MessageBox warning: 'Por favor, ingrese los datos solicitados. No puede cancelar la operación.'.
        ] ifFalse: [
            (input = '') ifTrue: [
                MessageBox warning: 'Ingrese un valor por favor.'.
            ] ifFalse: [
                valido := true.
            ].
        ].
    ].
    input.
].

"2. Validador para Números"
"Además de evitar vacíos/nulos, usa la estructura 'on: Error do:' para atrapar la excepción si 'asNumber' falla al leer letras."
pedirNumero := [:mensaje |
    | num input valido |
    valido := false.
    num := 0.
    [valido] whileFalse: [
        input := Prompter prompt: mensaje.
        (input isNil) ifTrue: [
            MessageBox warning: 'Por favor, ingrese los datos solicitados. No puede cancelar la operación.'.
        ] ifFalse: [
            (input = '') ifTrue: [
                MessageBox warning: 'Ingrese un valor por favor.'.
            ] ifFalse: [
                [
                    num := input asNumber.
                    valido := true.
                ] on: Error do: [:e |
                    MessageBox errorMsg: 'Dato inválido. Debe ingresar un número. Intente nuevamente.'.
                ].
            ].
        ].
    ].
    num.
].

"3. Validador para Calificación (Rango 1 a 10)"
"Reutiliza el bloque pedirNumero pero le agrega una validación lógica con operador &"
pedirCalificacion := [:mensaje |
    | num cValido |
    cValido := false.
    num := 0.
    [cValido] whileFalse: [
        num := pedirNumero value: mensaje.
        ((num >= 1) & (num <= 10)) ifTrue: [
            cValido := true.
        ] ifFalse: [
            MessageBox warning: 'Ingrese un valor coherente (1 a 10).'.
        ].
    ].
    num.
].
