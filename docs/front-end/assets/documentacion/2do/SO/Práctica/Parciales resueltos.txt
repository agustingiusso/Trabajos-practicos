1. Realizar un script que reciba un directorio por parametro y lo recorra haciendo lo siguiente:
A los archivos que tengan mas de 10 lineas debe dejar solo las primeras 10 lineas en un archivo nuevo llamado "nombre_archivo_recortado"
(por ejemplo si el archivo se llama script_ejemplo.sh el nombre del archivo recortado deberia ser script_ejemplo.sh_recortado),
finalmente debe informar la cantidad de archivos que se recortaron, y el promedio de lineas que tienen los archivos originales (o sea antes de ser recortados).

#!/bin/bash

# Validamos que se haya pasado exactamente 1 parámetro y que sea un directorio válido
if [ $# -ne 1 ] || [ ! -d "$1" ]; then
  echo "Error: Debe ingresar un directorio válido como parámetro."
  exit 1
fi

# Inicializamos los contadores
archivos_recortados=0
total_lineas=0
total_archivos=0

# Recorremos los elementos del directorio
for arch in "$1"/*; do
  
  # Verificamos que sea un archivo ordinario (común)
  if [ -f "$arch" ]; then
    
    # Contamos la cantidad de líneas del archivo original
    lineas=$(wc -l < "$arch")
    
    # Sumamos a los totales generales para el cálculo del promedio
    total_lineas=$((total_lineas + lineas))
    total_archivos=$((total_archivos + 1))
    
    # Si el archivo tiene más de 10 líneas, procedemos a recortarlo
    if [ "$lineas" -gt 10 ]; then
      # Extraemos las primeras 10 líneas y las guardamos en el nuevo archivo
      head -n 10 "$arch" > "${arch}_recortado"
      
      # Incrementamos el contador de archivos que fueron recortados
      archivos_recortados=$((archivos_recortados + 1))
    fi
  fi
done

# Mostramos la cantidad de archivos que se recortaron
echo "Cantidad de archivos que se recortaron: $archivos_recortados"

# Calculamos y mostramos el promedio de líneas de los archivos originales
if [ "$total_archivos" -gt 0 ]; then
  promedio=$((total_lineas / total_archivos))
  echo "El promedio de líneas de los archivos originales es: $promedio"
else
  echo "No se encontraron archivos ordinarios para analizar."
fi

2. Realizar un script que reciba un directorio por parametro y lo recorra haciendo lo siguiente:
A los archivos que tengan mas de 20 lineas, enviarlos a un directorio llamado "archivos_extensos", luego comprimir y empaquetar dicho directorio,
informar cuantos archivos se encontraron con mas de 20 lineas, cual es su tamaño sumado total,
y el porcentaje de archivos que era con respecto a la cantidad de archivos que existen en el directorio pasado por parametro.

#!/bin/bash

# 1. Validamos que se reciba exactamente 1 parámetro y que sea un directorio
if [ $# -ne 1 ] || [ ! -d "$1" ]; then
  echo "Error: Debe ingresar un directorio válido como parámetro."
  exit 1
fi

# 2. Inicializamos variables y creamos el directorio de destino
dir_origen="$1"
dir_destino="archivos_extensos"

mkdir -p "$dir_destino"

total_archivos=0
archivos_extensos=0
tamano_total=0

# 3. Recorremos los elementos del directorio
for arch in "$dir_origen"/*; do
  
  # Verificamos que el elemento sea un archivo ordinario (común)
  if [ -f "$arch" ]; then
    total_archivos=$((total_archivos + 1))
    
    # Contamos la cantidad de líneas del archivo
    lineas=$(wc -l < "$arch")
    
    # Si tiene más de 20 líneas, lo procesamos
    if [ "$lineas" -gt 20 ]; then
      
      # Obtenemos su tamaño en bytes antes de moverlo
      tamano=$(stat -c %s "$arch")
      
      # Sumamos al acumulador de tamaño y al contador de archivos extensos
      tamano_total=$((tamano_total + tamano))
      archivos_extensos=$((archivos_extensos + 1))
      
      # Movemos el archivo al nuevo directorio
      mv "$arch" "$dir_destino/"
    fi
  fi
done

# 4. Comprimimos y empaquetamos el directorio
# Solo lo hacemos si realmente se encontró y movió algún archivo
if [ "$archivos_extensos" -gt 0 ]; then
  tar -czf "${dir_destino}.tar.gz" "$dir_destino"
  echo "Directorio comprimido en '${dir_destino}.tar.gz'."
else
  echo "No se encontraron archivos con más de 20 líneas. No se generó el empaquetado."
fi

# 5. Calculamos el porcentaje
if [ "$total_archivos" -gt 0 ]; then
  # Multiplicamos por 100 primero para que la división entera de Bash funcione como porcentaje
  porcentaje=$(( (archivos_extensos * 100) / total_archivos ))
else
  porcentaje=0
fi

# 6. Informe final por pantalla
echo "======================================================"
echo "                   INFORME FINAL                      "
echo "======================================================"
echo "Archivos con más de 20 líneas encontrados : $archivos_extensos"
echo "Tamaño total sumado de esos archivos      : $tamano_total bytes"
echo "Total de archivos analizados              : $total_archivos"
echo "Porcentaje respecto al total              : $porcentaje%"
echo "======================================================"

3. Hacer un script al cual se le pase como parámetro un nombre de usuario y un número que representa un tamaño en bytes.
El script debe imprimir la cantidad de ficheros que hay dentro (recursivamente) del home del usuario pasado como argumento, que tengan un tamaño en bytes mayor al número pasado como 2do argumento.
En caso de no encontrar ningún usuario en el sistema cuyo nombre sea exactamente igual al primer parámetro, imprimir el mensaje de error "usuario no encontrado".

#!/bin/bash

# 1. Validamos que se hayan pasado exactamente 2 parámetros
if [ $# -ne 2 ]; then
  echo "Error: Debe pasar exactamente 2 parámetros."
  echo "Uso: $0 <nombre_usuario> <tamaño_en_bytes>"
  exit 1
fi

usuario="$1"
tamano="$2"

# 2. Verificamos si el usuario existe exactamente en el sistema
# Buscamos en /etc/passwd la línea que empiece exactamente con el nombre de usuario
linea_usuario=$(grep "^$usuario:" /etc/passwd)

if [ -z "$linea_usuario" ]; then
  # Si la variable está vacía, el usuario no existe
  echo "usuario no encontrado"
  exit 1
fi

# 3. Extraemos la ruta del directorio home del usuario
# El home se encuentra en el 6to campo del archivo /etc/passwd separado por ':'
home_usuario=$(echo "$linea_usuario" | cut -d':' -f6)

# Verificamos por seguridad que el directorio home realmente exista
if [ ! -d "$home_usuario" ]; then
  echo "Error: El directorio home del usuario ($home_usuario) no existe."
  exit 1
fi

# 4. Buscamos recursivamente los archivos y los contamos
# Usamos find con -type f (solo archivos) y -size +Nc (mayor a N bytes)
# Los errores (ej. carpetas sin permiso de lectura) se mandan a /dev/null
cantidad=$(find "$home_usuario" -type f -size +${tamano}c 2>/dev/null | wc -l)

# 5. Imprimimos el resultado final
echo "Cantidad de ficheros en $home_usuario mayores a $tamano bytes: $cantidad"

6. Hacer un script que visualice un menú de dos opciones:
a) La primera llamada "Directorio" debe pedir un directorio por consula y devolver
(en caso de que exista) el tamaño del archivo más chico en Kb.
También se debe contabilizar la cantidad de archivos que terminen permisos 644
b) La segunda llamada "Archivo" debe pedir un archivo por consola y realizar las siguientes tareas:
Cambiar los permisos del archivo para que solo pueda ser ejecutado por el dueño
Copiar el archivo a un nuevo archivo con el nombre "archivo-copiado"
Borrar las últimas 5 líneas del archivo y guardar la salida en un archivo
llamado que el original con el agregado al final del nombre "-mod"

#!/bin/bash

# Inicializamos la variable vacía para que el bucle arranque
opcion=""

# Bucle estructurado: se repite MIENTRAS la opción sea distinta de "s" y "S"
while [ "$opcion" != "s" ] && [ "$opcion" != "S" ]; do
  
  echo "=============== MENÚ ==============="
  echo "a) Directorio"
  echo "b) Archivo"
  echo "s) Salir"
  echo "===================================="
  read -p "Seleccione una opción: " opcion

  case $opcion in
    a|A)
      # ------------------------------------
      # OPCIÓN A: DIRECTORIO
      # ------------------------------------
      read -p "Ingrese la ruta de un directorio: " dir
      
      # Verificamos que el directorio exista
      if [ -d "$dir" ]; then
        min_tamano=-1
        cant_644=0
        
        # Recorremos los elementos dentro del directorio
        for arch in "$dir"/*; do
          
          # Solo procesamos si es un archivo ordinario
          if [ -f "$arch" ]; then
            
            # 1. Calculamos el tamaño en Kb (1 Kb = 1024 bytes)
            tam_bytes=$(stat -c %s "$arch")
            tam_kb=$((tam_bytes / 1024))
            
            # Si es el primer archivo (min_tamano=-1) o si es más chico que el mínimo actual
            if [ "$min_tamano" -eq -1 ] || [ "$tam_kb" -lt "$min_tamano" ]; then
              min_tamano=$tam_kb
            fi
            
            # 2. Contabilizamos si tiene permisos 644
            permisos=$(stat -c %a "$arch")
            if [ "$permisos" == "644" ]; then
              cant_644=$((cant_644 + 1))
            fi
            
          fi
        done
        
        # Mostrar los resultados si se encontraron archivos
        if [ "$min_tamano" -ne -1 ]; then
          echo "--> El tamaño del archivo más chico es: $min_tamano Kb."
        else
          echo "--> No se encontraron archivos ordinarios en el directorio."

        echo "Error: El directorio '$dir' no existe."

      # OPCIÓN B: ARCHIVO

        # 1. Cambiar permisos para que SOLO el dueño pueda ejecutarlo

        echo "--> Se actualizaron los permisos (solo el dueño puede ejecutarlo)."
        
        # 2. Copiar a un nuevo archivo llamado "archivo-copiado"
        cp "$arch" "archivo-copiado"
        echo "--> Se copió el archivo como 'archivo-copiado'."
        
        # 3. Borrar las últimas 5 líneas y guardar en "nombre-mod"
        lineas=$(wc -l < "$arch")
        limite=$((lineas - 5))
        
        if [ "$limite" -gt 0 ]; then
          # Si tiene más de 5 líneas, extraemos hasta el límite
          head -n "$limite" "$arch" > "${arch}-mod"
        else
          # Si tiene 5 líneas o menos, el archivo resultante queda vacío

#!/bin/bash

cd "$HOME" || exit 1

# 2. Limpiar la pantalla
clear

tar -czf usu64.tar.gz solo64 sindescrip user

echo "Proceso finalizado. El archivo 'usu64.tar.gz' ha sido creado en su directorio home."
