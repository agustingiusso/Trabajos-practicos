4- Explique cuál es la finalidad de actualizar un sistema operativo.

La finalidad de actualizar un sistema operativo es corregir errores (bugs) de versiones anteriores, tapar agujeros de seguridad o vulnerabilidades, mejorar el rendimiento general del sistema, garantizar compatibilidad con nuevo hardware y añadir nuevas funciones o características que mejoran la experiencia del usuario.

5- ¿Qué es un gestor de arranque?

Un gestor de arranque (como GRUB en Linux o Windows Boot Manager) es el primer programa que se ejecuta cuando se enciende una computadora. Su finalidad es cargar el sistema operativo en la memoria RAM para que pueda iniciar. Si hay varios sistemas operativos instalados, el gestor de arranque muestra un menú para que el usuario elija con cuál quiere iniciar.

6- Qué es un intérprete de comandos, y decir cual se instaló por defecto (default) en su máquina, al momento de instalar el Sistema Operativo.

Un intérprete de comandos (o shell) es un programa informático que tiene la capacidad de traducir las órdenes que el usuario introduce (en formato de texto) en instrucciones que el sistema operativo puede entender y ejecutar.
En Ubuntu Linux (y la mayoría de las distribuciones GNU/Linux), el intérprete de comandos instalado por defecto se llama Bash (Bourne Again Shell).

7- Realizar una breve descripción del directorio raíz ( / ) (sistema de Archivo), indicando qué se aloja en cada directorio del Sistema (solamente los directorios del raíz).

El directorio raíz (/) es la base de la jerarquía de archivos en Linux. Sus principales subdirectorios alojan lo siguiente:
/bin: Comandos binarios esenciales para todos los usuarios (ej. ls, cp, bash).
/boot: Archivos estáticos necesarios para el arranque del sistema (ej. kernel, GRUB).
/dev: Archivos de dispositivos (hardware como discos, teclados, puertos).
/etc: Archivos de configuración del sistema y de los programas instalados.
/home: Directorios personales de los usuarios (documentos, descargas, escritorio).
/lib: Bibliotecas compartidas esenciales y módulos del kernel.
/media o /mnt: Puntos de montaje para medios extraíbles (USB, CD-ROM) o temporales.
/opt: Paquetes de software de aplicaciones de terceros.
/root: Directorio personal del súper-usuario (Administrador).
/sbin: Binarios esenciales para la administración del sistema (usados por root).
/tmp: Archivos temporales creados por el sistema o aplicaciones.
/usr: Utilidades y aplicaciones de usuario (segunda jerarquía más grande).
/var: Archivos de datos variables, como registros del sistema (logs) y bases de datos.

13- Investigar sobre el protocolo e implementación de SSH

SSH (Secure Shell) es un protocolo de red criptográfico que permite operar servicios de red de forma segura sobre una red no segura. Su uso más común es el inicio de sesión remoto en sistemas informáticos por parte de usuarios a través de una consola de comandos. SSH cifra todo el tráfico entre el cliente y el servidor (incluyendo contraseñas), mitigando ataques como el "sniffing". La implementación de código abierto más famosa y utilizada en sistemas Linux/Unix es OpenSSH.

usu01:x:uid:guid: :/home/usu01:/bin/bash (línea que debe agregar al archivo usuarios)
El usuario usu01 debe ser pasado como argumento

#!/bin/bash
# Verificar que se pasó un argumento
if [ -z "$1" ]; then
    echo "Error: El usuario debe ser pasado como argumento."
    echo "Uso: ./ejercicio10.sh <nombre_usuario>"
    exit 1
fi

USUARIO=$1
ARCHIVO="usuarios"

    touch "$ARCHIVO"
fi

# Buscar el último ID ingresado (tomamos el UID del último registro). 
# Si el archivo está vacío, comenzamos desde 1000.
ultimo_uid=$(tail -n 1 "$ARCHIVO" | cut -d":" -f3)
ultimo_guid=$(tail -n 1 "$ARCHIVO" | cut -d":" -f4)

if [ -z "$ultimo_uid" ]; then
    uid=1000
    guid=1000
else
    # Sumar 1 usando let (o aritmética de bash)
    let uid=$ultimo_uid+1
    let guid=$ultimo_guid+1
fi

echo "${USUARIO}:x:${uid}:${guid}::/home/${USUARIO}:/bin/bash" >> "$ARCHIVO"
echo "El usuario $USUARIO ha sido dado de alta exitosamente en el archivo '$ARCHIVO'."
