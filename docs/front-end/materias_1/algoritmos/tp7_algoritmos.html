Ejercicio 1: Seguimiento de Función Recursiva

Dado un programa con una función recursiva f(n) donde para n=0 es 1, n=1 es 2, n=2 es 3, y en otro caso es f(n-2) * f(n-4).
a) ¿Cuál es el valor final de temp = f(8)? Utilizar el método de las cajas.
b) ¿Existen valores que podrían causar que las llamadas recursivas no terminen?

Análisis y Traza (Método de las cajas):

  • a) Cálculo de f(8):
    f(8) = f(6) * f(4)
        Calculamos f(4): f(4) = f(2) * f(0) = 3 * 1 = 3
        Calculamos f(6): f(6) = f(4) * f(2) = 3 * 3 = 9
        Finalmente: f(8) = 9 * 3 = 27. El valor de temp será 27.
  • b) Valores de bucle infinito: Sí, la función no terminará si se invoca con números impares mayores o iguales a 3, o con números negativos. Por ejemplo, f(3) llama a f(1) * f(-1), y f(-1) llamará a f(-3) * f(-5) alejándose infinitamente de los casos base (0, 1, 2) generando un Stack Overflow.
#include <stdio.h>

int f(int n) {
    if (n == 0) {
        return 1;
    } else if (n == 1) {
        return 2;
    } else if (n == 2) {
        return 3;
    } else {
        return f(n - 2) * f(n - 4);
    }
}

int main() {
    int temp;
    temp = f(8);
    printf("El valor de f(8) es: %d\n", temp);
    
    // Descomentar para probar recursión infinita (provocará cuelgue):
    // printf("f(3) = %d\n", f(3)); 
    
    return 0;
}

Ejercicio 2: Recursión con palabras y frases

Implementar una solución recursiva para: a) Imprimir en forma invertida una palabra. b) Retornar la cantidad de palabras de una frase terminada en '.' (las palabras vienen separadas por un espacio en blanco).

#include <stdio.h>

// a) Invertir palabra recursivamente
void imprimirInvertida(char str[], int idx) {
    if (str[idx] == '\0') {
        return; // Caso base: fin de la cadena
    }
    imprimirInvertida(str, idx + 1);
    printf("%c", str[idx]);
}

// b) Contar palabras de una frase leida caracter a caracter hasta '.'
int contarPalabrasRecursivo() {
    char c = getchar();
    
    if (c == '.') {
        return 1; // La ultima palabra antes del punto cuenta como 1
    }
    if (c == ' ') {
        return 1 + contarPalabrasRecursivo(); // Hay un espacio, suma una palabra
    }
    
    return contarPalabrasRecursivo(); // Sigue consumiendo letras
}

int main() {
    char palabra[] = "RECURSION";
    
    printf("Palabra original: %s\n", palabra);
    printf("Palabra invertida: ");
    imprimirInvertida(palabra, 0);
    printf("\n\n");
    
    printf("Ingrese una frase terminada en punto (.):\n");
    int cant_palabras = contarPalabrasRecursivo();
    printf("\nCantidad de palabras: %d\n", cant_palabras);
    
    return 0;
}

Ejercicio 3: Conteo de Vocales

Escribir una función recursiva para contar la cantidad de vocales que posee una cadena de caracteres S. Ejemplo: si S = 'Práctica de Algoritmos' la función retorna 8.

#include <stdio.h>

// Función para verificar si un char es vocal (sin importar acentos en C estándar para simplificar)
int esVocal(char c) {
    if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u' ||
        c == 'A' || c == 'E' || c == 'I' || c == 'O' || c == 'U') {
        return 1;
    }
    return 0;
}

int contarVocales(char str[], int idx) {
    if (str[idx] == '\0') {
        return 0; // Caso base: no hay más caracteres
    }
    
    if (esVocal(str[idx])) {
        return 1 + contarVocales(str, idx + 1);
    } else {
        return contarVocales(str, idx + 1);
    }
}

int main() {
    char frase[] = "Practica de Algoritmos";
    
    int total_vocales = contarVocales(frase, 0);
    
    printf("La frase es: \"%s\"\n", frase);
    printf("Cantidad total de vocales: %d\n", total_vocales);
    
    return 0;
}

Ejercicio 4: Serie de Fibonacci

La serie de Fibonacci se define de la siguiente manera: F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2) con n>1. Implementar una función recursiva para obtener los números de Fibonacci.

#include <stdio.h>

int fibonacci(int n) {
    if (n == 0) {
        return 0; // Caso base 1
    } else if (n == 1) {
        return 1; // Caso base 2
    } else {
        return fibonacci(n - 1) + fibonacci(n - 2); // Llamada recursiva doble
    }
}

int main() {
    int numero;
    
    printf("Ingrese que termino de la serie de Fibonacci desea calcular: ");
    scanf("%d", &numero);
    
    if (numero >= 0) {
        int resultado = fibonacci(numero);
        printf("El termino F(%d) de la serie de Fibonacci es: %d\n", numero, resultado);
    } else {
        printf("Error: La serie esta definida para n >= 0.\n");
    }
    
    return 0;
}

Ejercicio 5: Detección de Palíndromos

Escribir una función recursiva para determinar si una palabra es un palíndromo. Ej: ananá es un palíndromo.

#include <stdio.h>
#include <string.h>

int esPalindromo(char str[], int inicio, int fin) {
    // Si los punteros se cruzan o igualan, es porque todos los pares coincidieron
    if (inicio >= fin) {
        return 1; // Verdadero
    }
    
    // Si los extremos son distintos, no es palíndromo
    if (str[inicio] != str[fin]) {
        return 0; // Falso
    }
    
    // Llamada recursiva acortando los extremos
    return esPalindromo(str, inicio + 1, fin - 1);
}

int main() {
    char palabra[50];
    
    printf("Ingrese una palabra: ");
    scanf("%s", palabra);
    
    int longitud = strlen(palabra);
    
    if (esPalindromo(palabra, 0, longitud - 1)) {
        printf("La palabra '%s' SI es un palindromo.\n", palabra);
    } else {
        printf("La palabra '%s' NO es un palindromo.\n", palabra);
    }
    
    return 0;
}

Ejercicio 6: Decimal a Binario Recursivo

Realizar un procedimiento recursivo que reciba un valor entero e imprima su equivalente en sistema binario. Recordar que hay que dividirlo por 2, y tomar el resultado entero de la división y obtener el resto para imprimir al revés.

Al hacer la impresión después de la llamada recursiva, el programa primero desciende hasta el último cociente y, a medida que la recursión vuelve hacia atrás, imprime los restos en orden invertido, logrando el número binario correctamente.

#include <stdio.h>

void imprimirBinario(int n) {
    if (n > 1) {
        imprimirBinario(n / 2); // Llamada recursiva con la parte entera de la division
    }
    printf("%d", n % 2); // Se imprime a la vuelta de la recursion
}

int main() {
    int numero;
    
    printf("Ingrese un numero decimal: ");
    scanf("%d", &numero);
    
    if (numero >= 0) {
        printf("El equivalente en binario de %d es: ", numero);
        imprimirBinario(numero);
        printf("\n");
    } else {
        printf("Error: Ingrese un numero positivo.\n");
    }
    
    return 0;
}

Ejercicio 7: Pasaje de Parámetros (Copia vs Referencia)

Se tiene el procedimiento Prueba(x, y). Si y>0, hace x=x+1 y y=y-1, imprime x,y, se llama a Prueba(x,y), y vuelve a imprimir x,y. Analizar traza suponiendo que se llama con x=5 e y=3: a) Parámetros pasados por copia, b) Parámetro x pasado por referencia.

Traza (Método de las Cajas):

  • a) Por copia (Valor): Cada llamada crea una copia local. Las impresiones se "desarman" (unwind) con los mismos valores locales.
    Ida: Imprime 6 2, luego 7 1, luego 8 0.
    Vuelta: Imprime 8 0, luego 7 1, luego 6 2.
  • b) Por Referencia (para 'x'): Todas las llamadas modifican el MISMO x en memoria, por lo que x terminará siendo 8. En la vuelta, las variables locales y mantienen su valor de cada entorno, pero el x único vale 8 en todas partes.
    Ida: Imprime 6 2, luego 7 1, luego 8 0.
    Vuelta: Imprime 8 0, luego 8 1, luego 8 2. 
#include <stdio.h>

// A) Pasaje por copia (valor)
void PruebaCopia(int x, int y) {
    if (y > 0) {
        x = x + 1;
        y = y - 1;
        printf("Ida copia: x=%d, y=%d\n", x, y);
        PruebaCopia(x, y);
        printf("Vuelta copia: x=%d, y=%d\n", x, y);
    }
}

// B) Pasaje por referencia (Puntero para x)
void PruebaRef(int *x, int y) {
    if (y > 0) {
        *x = *x + 1;
        y = y - 1;
        printf("Ida ref: x=%d, y=%d\n", *x, y);
        PruebaRef(x, y);
        printf("Vuelta ref: x=%d, y=%d\n", *x, y);
    }
}

int main() {
    int val_x = 5, val_y = 3;
    
    printf("--- A) PRUEBA POR COPIA ---\n");
    PruebaCopia(val_x, val_y);
    
    printf("\n--- B) PRUEBA POR REFERENCIA ---\n");
    // Restablecemos variables
    val_x = 5; val_y = 3;
    PruebaRef(&val_x, val_y);
    
    return 0;
}

Ejercicio 8: Recursión con Arreglos

Aplicando recursión en estructura de arreglos de enteros:
a) Sumar los elementos de un vector.
b) Contar la cantidad de elementos múltiplos de 3.
c) Cuántos elementos pares ocupan posiciones impares (de izquierda a derecha).

Para el punto C, las posiciones "de izquierda a derecha" se consideran naturales, por lo que la posición del índice 0 es la 1 (impar), la posición del índice 1 es la 2 (par), y así sucesivamente.

#include <stdio.h>

// A) Sumar elementos de un vector
int sumarVector(int vec[], int n, int idx) {
    if (idx >= n) return 0; // Caso base
    return vec[idx] + sumarVector(vec, n, idx + 1);
}

// B) Contar multiplos de 3
int contarMultiplosDe3(int vec[], int n, int idx) {
    if (idx >= n) return 0;
    
    int cuenta = (vec[idx] % 3 == 0) ? 1 : 0;
    return cuenta + contarMultiplosDe3(vec, n, idx + 1);
}

// C) Elementos pares en posiciones impares (Posicion 1 = indice 0)
int paresEnPosImpar(int vec[], int n, int idx) {
    if (idx >= n) return 0;
    
    int posicion_real = idx + 1;
    int cuenta = 0;
    
    // Si la posicion es impar y el contenido es par
    if (posicion_real % 2 != 0 && vec[idx] % 2 == 0) {
        cuenta = 1;
    }
    
    return cuenta + paresEnPosImpar(vec, n, idx + 1);
}

int main() {
    int vector[6] = {4, 9, 2, 12, 5, 6};
    int tam = 6;
    
    printf("Vector de prueba: [4, 9, 2, 12, 5, 6]\n\n");
    
    int suma = sumarVector(vector, tam, 0);
    printf("a) Suma total de elementos: %d\n", suma);
    
    int multiplos = contarMultiplosDe3(vector, tam, 0);
    printf("b) Cantidad de multiplos de 3: %d\n", multiplos);
    
    int pares_imp = paresEnPosImpar(vector, tam, 0);
    printf("c) Pares en posiciones impares: %d\n", pares_imp);
    
    return 0;
}
