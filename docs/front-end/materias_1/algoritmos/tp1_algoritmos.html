Ejercicio 1: Liquidación y recibo de sueldo

Una empresa desea calcular el sueldo de un empleado e imprimir su recibo detallando: Nombre y Apellido, Sueldo Básico, Premio, Comida, Viáticos, Ausentes, Obra social (3%), Ley 19032 (3%), y Jubilación (11%). Por los ausentes, se descuenta un monto fijo por día de ausencia. Los porcentajes se calculan sobre los montos remunerativos. Viáticos, premios y comida no se consideran remunerativos.

#include <stdio.h>

int main()
{
    // Declaración de variables:
    char nombre[50];
    char apellido[50];
    float sueldo_basico;
    float premio;
    float comida;
    float viaticos;
    int ausentes;
    float descuento_ausentes, total_ausentes;
    float monto_remunerativo, monto_no_remunerativo;
    float obra_social, ley_19032, jubilacion, total_descuentos;
    float sueldo_bruto;
    float sueldo_neto;

    // Ingreso de datos:
    printf("Ingrese el nombre del empleado: ");
    scanf("%s", nombre);

    printf("Ingrese el apellido del empleado: ");
    scanf("%s", apellido);

    printf("Ingrese el sueldo basico: ");
    scanf("%f", &sueldo_basico);

    printf("Ingrese el premio: ");
    scanf("%f", &premio);

    printf("Ingrese el monto de comida: ");
    scanf("%f", &comida);

    printf("Ingrese el monto de viaticos: ");
    scanf("%f", &viaticos);

    printf("Ingrese la cantidad de dias ausentes: ");
    scanf("%d", &ausentes);

    printf("Ingrese el monto fijo por dia de ausencia: ");
    scanf("%f", &descuento_ausentes);

    // Cálculo de haberes y retenciones sobre monto remunerativo:
    total_ausentes = ausentes * descuento_ausentes;
    monto_remunerativo = sueldo_basico - total_ausentes;
    monto_no_remunerativo = premio + comida + viaticos;

    obra_social = monto_remunerativo * 0.03;
    ley_19032 = monto_remunerativo * 0.03;
    jubilacion = monto_remunerativo * 0.11;

    total_descuentos = obra_social + ley_19032 + jubilacion;
    sueldo_bruto = monto_remunerativo + monto_no_remunerativo;
    sueldo_neto = sueldo_bruto - total_descuentos;

    // Impresión del recibo:
    printf("\n================ RECIBO DE SUELDO ================\n");
    printf("Empleado: %s %s\n", nombre, apellido);
    printf("--------------------------------------------------\n");
    printf("Sueldo Basico:               $ %.2f\n", sueldo_basico);
    printf("Ausentes (%d dias):          -$ %.2f\n", ausentes, total_ausentes);
    printf("Premio (No rem.):            $ %.2f\n", premio);
    printf("Comida (No rem.):            $ %.2f\n", comida);
    printf("Viaticos (No rem.):          $ %.2f\n", viaticos);
    printf("--------------------------------------------------\n");
    printf("Obra Social (3%%):           -$ %.2f\n", obra_social);
    printf("Ley 19032 (3%%):             -$ %.2f\n", ley_19032);
    printf("Jubilacion (11%%):           -$ %.2f\n", jubilacion);
    printf("--------------------------------------------------\n");
    printf("Sueldo Bruto:                $ %.2f\n", sueldo_bruto);
    printf("Total Retenciones:          -$ %.2f\n", total_descuentos);
    printf("SUELDO NETO A COBRAR:        $ %.2f\n", sueldo_neto);
    printf("==================================================\n");

    return 0;
}

Ejercicio 2: Recibo de uso en librería e Internet

Una Librería cobra $10 el minuto de uso de una computadora con conexión a Internet, y $15 la hoja impresa. Existe un cargo adicional consistente en $5 * X, siendo X el 1% del tiempo utilizado, en concepto de seguro. Se quiere imprimir el recibo de uso de un cliente, en el que se detallen todos los conceptos.

#include <stdio.h>

int main()
{
    float minutos = 0, x = 0;
    int hojas = 0;
    float costo_internet = 0, costo_impresion = 0, costo_seguro = 0, total = 0;

    printf("Ingrese los minutos de uso de la computadora: ");
    scanf("%f", &minutos);

    printf("Ingrese la cantidad de hojas impresas: ");
    scanf("%d", &hojas);

    // Cálculos de los conceptos:
    costo_internet = minutos * 10.0;
    costo_impresion = hojas * 15.0;
    x = minutos * 0.01;
    costo_seguro = 5.0 * x;
    total = costo_internet + costo_impresion + costo_seguro;

    // Salida del recibo detallado:
    printf("\n============= RECIBO DE USO - LIBRERIA =============\n");
    printf("Uso de Internet (%.2f min x $10):     $ %.2f\n", minutos, costo_internet);
    printf("Hojas impresas (%d hojas x $15):      $ %.2f\n", hojas, costo_impresion);
    printf("Cargo de seguro ($5 x %.2f):          $ %.2f\n", x, costo_seguro);
    printf("----------------------------------------------------\n");
    printf("TOTAL A ABONAR:                       $ %.2f\n", total);
    printf("====================================================\n");

    return 0;
}

Ejercicio 5: Censo de grado de alfabetización

En el último censo, una de las preguntas se refirió al "grado de alfabetización" de la población mayor de 18 años. Se utilizaron las siguientes categorías: "sin escolaridad", "primaria completa", "secundaria completa", "universitaria completa". Se conoce la cantidad de hombres y mujeres correspondientes a cada categoría y se desea generar un reporte identificando los porcentajes parciales, como se muestra a continuación: Total de mujeres encuestadas: M. Ejercicio 1: Unificación de condiciones con un solo condicional

Si se analiza el pseudocódigo del ejemplo, se destaca que cada una de las condiciones llevaban a hacer exactamente lo mismo en caso de que cualquiera de ellas fuese verdadera, y sólo se hacía algo diferente en el caso en que TODAS ellas resultaban falsas. Encontrar una manera de construir una condición que permita expresar lo que acabamos de mencionar, de modo que el programa resultante utilice una sola sentencia SI para decidir.

Para unificar los tres condicionales anidados del problema de ejemplo (determinar si la suma de cualquier pareja de tres números reales es igual al tercero) en una única sentencia de decisión, vinculo las tres comparaciones mediante el operador lógico disyuntivo OR (|| en lenguaje C). De esta forma, basta con que al menos una de las igualdades se cumpla para imprimir "Son Iguales....!":

#include <stdio.h>

int main()
{
    float A = 0, B = 0, C = 0;

    printf("Ingrese el primer valor: ");
    scanf("%f", &A);
    printf("Ingrese el segundo valor: ");
    scanf("%f", &B);
    printf("Ingrese el tercer valor: ");
    scanf("%f", &C);

    // Única sentencia if combinando las tres condiciones con el operador OR (||):
    if ((A + B) == C || (A + C) == B || (B + C) == A)
    {
        printf("Son Iguales....!\n");
    }
    else
    {
        printf("Son Distintos...!\n");
    }

    return 0;
}

Ejercicio 4: Ticket de compra de dólares con comisión bancaria

Un empleado de banco tiene un sistema que imprime un ticket cada vez que un cliente realiza una compra de dólares. La operación tiene una comisión administrativa según la cantidad de dólares que se venden, lo que representa un sobre costo para el cliente: a. 2% si es más de 501 y menos de 1501 b. 2,5% si es mayor de 1501 y menos que 3501 c. 4% si es mayor a 3501 El ticket muestra discriminados: la cantidad de dólares que se compraron, el valor de cada dólar, el monto de la comisión y el monto total que el cliente debe abonar por la compra. Hacer un programa que simule la compra e imprima el ticket.

#include <stdio.h>

int main()
{
    float cant_dolares = 0, cotizacion = 0;
    float subtotal = 0, porcentaje_comision = 0, monto_comision = 0, total_abonar = 0;

    printf("Ingrese la cantidad de dolares a comprar: ");
    scanf("%f", &cant_dolares);

    printf("Ingrese la cotizacion de cada dolar (en pesos): ");
    scanf("%f", &cotizacion);

    subtotal = cant_dolares * cotizacion;

    if (cant_dolares > 501 && cant_dolares < 1501)
    {
        porcentaje_comision = 0.02;
    }
    else if (cant_dolares > 1501 && cant_dolares < 3501)
    {
        porcentaje_comision = 0.025;
    }
    else if (cant_dolares > 3501)
    {
        porcentaje_comision = 0.04;
    }
    else
    {
        porcentaje_comision = 0.0;
    }

    monto_comision = subtotal * porcentaje_comision;
    total_abonar = subtotal + monto_comision;

    printf("\n============== TICKET BANCARIO ==============\n");
    printf("Cantidad comprada:        USD %.2f\n", cant_dolares);
    printf("Valor de cada dolar:      $ %.2f\n", cotizacion);
    printf("Subtotal:                 $ %.2f\n", subtotal);
    printf("Monto de comision (%.1f%%): $ %.2f\n", porcentaje_comision * 100, monto_comision);
    printf("---------------------------------------------\n");
    printf("MONTO TOTAL A ABONAR:     $ %.2f\n", total_abonar);
    printf("=============================================\n");

    return 0;
}

Ejercicio 5: Mayor de dos números y optimización de condiciones

Diseñar un algoritmo que calcule el mayor de dos números dados. ¿Cuántas condiciones requiere evaluar su algoritmo? ¿Podría codificar otro que utilice menos? ¿Y otro que utilice menos sentencias SI?

Análisis Teórico:

  • ¿Cuántas condiciones requiere evaluar mi algoritmo? Si solo necesito obtener el valor máximo entre dos números a y b (sin importar si son iguales), requiero evaluar 1 sola condición (a > b) con una única estructura if / else. Si además quiero distinguir explícitamente el caso de igualdad, necesito 2 condiciones (a > b y b > a).
  • ¿Podría codificar otro que utilice menos condiciones? Si asumo inicialmente que el mayor es el primer número (mayor = a), sigo evaluando 1 condición (if (b > mayor)), pero me ahorro la rama else.
  • ¿Y otro que utilice menos sentencias SI? Sí, en lenguaje C puedo prescindir por completo de la sentencia if utilizando una fórmula matemática con valor absoluto: $\text{mayor} = \frac{a + b + |a - b|}{2}$.
#include <stdio.h>
#include <math.h>

int main()
{
    float a = 0, b = 0, mayor = 0;

    printf("Ingrese dos numeros reales: ");
    scanf("%f %f", &a, &b);

    // Versión 1: 1 sola sentencia if y sin rama else (asigna por defecto)
    mayor = a;
    if (b > mayor)
    {
        mayor = b;
    }
    printf("El mayor (con 1 sentencia if) es: %.2f\n", mayor);

    // Versión 2: 0 sentencias if (fórmula matemática con fabs)
    mayor = (a + b + fabs(a - b)) / 2.0;
    printf("El mayor (con 0 sentencias if) es: %.2f\n", mayor);

    return 0;
}

Ejercicio 6: Detección de errores de sintaxis en condicionales

¿Qué errores de sintaxis se detectan en los siguientes grupos de sentencias? a) Si (A > 0) Entonces Si (B > 0) Entonces C := A + B Sino C := A + 3 * C D := A - B - C b) Si (A > 0) Imprimir: 'Es Mayor...' Sino Imprimir: 'Es menor...' Si Imprimir: 'Son Iguales...' Fin Si Analizar y mostrar todos los posibles códigos resultantes de intentar corregir el / los error(es) encontrado(s).

Análisis de Errores Detectados:

  • Inciso a): Faltan los cierres de bloque (Fin Si). Al haber dos Si abiertos y un solo Sino sin delimitadores de cierre, se produce el problema clásico de ambigüedad del dangling else: no queda definido si el Sino pertenece al Si (A > 0) externo (como sugiere la indentación) o al Si (B > 0) interno, ni si la instrucción D := A - B - C forma parte del bloque condicional o se ejecuta siempre fuera de él.
  • Inciso b):
    1. Al primer Si (A > 0) le falta la palabra clave Entonces y su respectivo cierre Fin Si.
    2. El segundo Si carece por completo de condición booleana a evaluar (debería ser A == 0) y de la palabra Entonces, además de estar mal anidado luego de un Sino que ya había cubierto el caso $A \le 0$.

A continuación implemento en C todas las variantes válidas resultantes de corregir ambos fragmentos:

Ejercicio 12: Mayor de tres números y análisis de condiciones

Diseñar un algoritmo que calcule el mayor de 3 números dados. ¿Cuántas condiciones requiere evaluar su algoritmo? ¿Podría codificar otro que utilice menos? ¿Y otro que utilice menos sentencias SI?

Análisis Teórico:

  • ¿Cuántas condiciones requiere evaluar el algoritmo? Si utilizo condiciones compuestas independientes (ej. a >= b && a >= c), en el peor caso se evalúan hasta 4 comparaciones relacionales. En cambio, usando una estructura anidada o una variable auxiliar (mayor = a), solo necesito evaluar 2 condiciones simples en total (b > mayor y c > mayor).
  • ¿Podría codificar otro que utilice menos sentencias SI? Sí: pasando de 3 sentencias if anidadas a 2 sentencias if secuenciales mediante una variable auxiliar, o incluso a 0 sentencias if anidando la función matemática de máximo con fabs() vista en el Ejercicio 5.
#include <stdio.h>

int main()
{
    float a = 0, b = 0, c = 0, mayor = 0;

    printf("Ingrese tres numeros separados por espacio: ");
    scanf("%f %f %f", &a, &b, &c);

    // Solución óptima: 2 condiciones simples y 2 sentencias if usando variable auxiliar
    mayor = a;

    if (b > mayor)
    {
        mayor = b;
    }

    if (c > mayor)
    {
        mayor = c;
    }

    printf("El mayor de los tres numeros es: %.2f\n", mayor);

    return 0;
}
