Ejercicio 1: Funciones para cálculo de máximos (2, 3, 5 y 10 números)

Codificar funciones para calcular: a. el máximo entre 2 números enteros b. el máximo entre 3 números enteros c. el máximo entre 5 números enteros d. el máximo entre 10 números enteros En cada inciso donde sea posible, hacer dos versiones: una que calcule el máximo usando las funciones definidas en los incisos anteriores, y otra que no las use. ¿En qué cambiaría el código si se pudiera calcular el máximo entre números reales?

Análisis Teórico:

¿En qué cambiaría el código para calcular el máximo entre números reales?
La lógica algorítmica y la composición de llamadas a las funciones no cambian en absoluto. Únicamente debo modificar la firma (encabezamiento) de cada función reemplazando el tipo de retorno y el tipo de todos los parámetros formales de int a float (o double), hacer lo mismo con las variables locales auxiliares (mayor) y cambiar el especificador de formato de %d a %f en las lecturas e impresiones del programa principal.

#include <stdio.h>

// a) Máximo entre 2 números enteros
int max2(int n1, int n2)
{
    return (n1 > n2) ? n1 : n2;
}

// b) Máximo entre 3 números (Versión 1: Usando max2)
int max3_compuesto(int n1, int n2, int n3)
{
    return max2(max2(n1, n2), n3);
}

// b) Máximo entre 3 números (Versión 2: Sin usar funciones previas)
int max3_directo(int n1, int n2, int n3)
{
    int mayor = n1;
    if (n2 > mayor) mayor = n2;
    if (n3 > mayor) mayor = n3;
    return mayor;
}

// c) Máximo entre 5 números (Versión 1: Usando max3 y max2)
int max5_compuesto(int n1, int n2, int n3, int n4, int n5)
{
    return max2(max3_compuesto(n1, n2, n3), max2(n4, n5));
}

// c) Máximo entre 5 números (Versión 2: Sin usar funciones previas)
int max5_directo(int n1, int n2, int n3, int n4, int n5)
{
    int mayor = n1;
    if (n2 > mayor) mayor = n2;
    if (n3 > mayor) mayor = n3;
    if (n4 > mayor) mayor = n4;
    if (n5 > mayor) mayor = n5;
    return mayor;
}

// d) Máximo entre 10 números (Versión 1: Usando max5 y max2)
int max10_compuesto(int n1, int n2, int n3, int n4, int n5,
                    int n6, int n7, int n8, int n9, int n10)
{
    return max2(max5_compuesto(n1, n2, n3, n4, n5),
                max5_compuesto(n6, n7, n8, n9, n10));
}

// d) Máximo entre 10 números (Versión 2: Sin usar funciones previas)
int max10_directo(int n1, int n2, int n3, int n4, int n5,
                  int n6, int n7, int n8, int n9, int n10)

    int mayor = n1;
    if (n2 > mayor) mayor = n2;
    if (n3 > mayor) mayor = n3;
    if (n4 > mayor) mayor = n4;
    if (n5 > mayor) mayor = n5;
    if (n6 > mayor) mayor = n6;
    if (n7 > mayor) mayor = n7;
    if (n8 > mayor) mayor = n8;
    if (n9 > mayor) mayor = n9;
    if (n10 > mayor) mayor = n10;

int main()
{
    int a, b, c, d, e, f, g, h, i, j;

    printf("Ingrese 10 numeros enteros separados por espacio:\n");
    scanf("%d %d %d %d %d %d %d %d %d %d",
          &a, &b, &c, &d, &e, &f, &g, &h, &i, &j);

    printf("\n--- Resultados de las Funciones ---\n");

           max10_compuesto(a, b, c, d, e, f, g, h, i, j),
           max10_directo(a, b, c, d, e, f, g, h, i, j));

    return 0;
}

Ejercicio 2: Distancia entre puntos del plano o del espacio

Diseñar una aplicación que ofrezca, a través de un menú, la posibilidad de calcular distancias entre puntos del plano o del espacio. Se deben codificar funciones que calculen las distancias a partir de las coordenadas de los puntos, que llegan como parámetros.

#include <stdio.h>
#include <math.h>

float distanciaPlano(float x1, float y1, float x2, float y2)
{
    return sqrt(pow(x2 - x1, 2) + pow(y2 - y1, 2));
}

float distanciaEspacio(float x1, float y1, float z1, float x2, float y2, float z2)
{
    return sqrt(pow(x2 - x1, 2) + pow(y2 - y1, 2) + pow(z2 - z1, 2));
}

int main()
{
    int opcion = 0;
    float x1 = 0, y1 = 0, z1 = 0, x2 = 0, y2 = 0, z2 = 0;

    do
    {
        printf("\n========= MENU CALCULO DE DISTANCIAS =========\n");
        printf("1. Distancia entre dos puntos en el Plano (2D)\n");
        printf("2. Distancia entre dos puntos en el Espacio (3D)\n");

Se deben codificar funciones que calculen las áreas de: círculo, cuadrado, rectángulo, triángulo y trapecio. Las fórmulas pueden buscarse en libros de geometría de nivel secundario (polimodal).

#include <stdio.h>

#define PI 3.14159265f

float areaCirculo(float radio)
{
    return PI * radio * radio;
}

float areaCuadrado(float lado)
{
    return lado * lado;
}

float areaRectangulo(float base, float altura)
{
    return base * altura;
}

float areaTriangulo(float base, float altura)
{
    return (base * altura) / 2.0f;
}

float areaTrapecio(float base_mayor, float base_menor, float altura)
{
    return ((base_mayor + base_menor) * altura) / 2.0f;
}

int main()
{
    int opcion = 0;

        printf("5. Trapecio\n");
        printf("0. Salir\n");

Ejercicio 4: Diseño con funciones o procedimientos según corresponda

Definir funciones o procedimientos, según convenga, para calcular: a. las raíces (reales o complejas) de una ecuación de 2do grado b. el promedio de 6 números enteros c. la conversión de temperaturas Celsius a Fahrenheit y viceversa d. el módulo de un vector del plano dadas sus coordenadas e. la suma de dos vectores dados del plano f. la conversión de letras mayúsculas a minúsculas y viceversa g. el valor del número PI usando la función primitiva ARCTAN

Criterio de Elección (Función vs. Procedimiento):

Siguiendo la teoría de la cátedra, utilizo funciones en los incisos b, c, d, f y g porque cada uno produce un único resultado escalar de tipo simple que puede retornarse en el nombre de la función para formar parte de una expresión. En cambio, en los incisos a (dos raíces más un indicador de si son reales o complejas conjugadas) y e (las dos componentes $(r_x, r_y)$ del vector suma resultante) utilizo procedimientos (void en C con pasaje de parámetros por referencia mediante punteros) ya que requieren devolver más de un dato de salida al módulo llamador:

#include <stdio.h>
#include <math.h>

// a) PROCEDIMIENTO: Devuelve 2 raíces (o parte real e imaginaria) y el tipo de raíz
void raicesCuadratica(float a, float b, float c, float *r1, float *r2, int *es_compleja)
{
    float disc = (b * b) - (4.0f * a * c);
    if (disc >= 0)
    {
        *es_compleja = 0;
        *r1 = (-b + sqrt(disc)) / (2.0f * a);
        *r2 = (-b - sqrt(disc)) / (2.0f * a);
    }
    else
    {
        *es_compleja = 1;
        *r1 = -b / (2.0f * a);            // Parte real
        *r2 = sqrt(-disc) / (2.0f * a);   // Parte imaginaria
    }
}

// b) FUNCIÓN: Promedio de 6 números enteros (retorna 1 único real)
float promedio6(int n1, int n2, int n3, int n4, int n5, int n6)
{
    return (n1 + n2 + n3 + n4 + n5 + n6) / 6.0f;
}

// c) FUNCIONES: Conversión entre Celsius y Fahrenheit
float celsiusAFahrenheit(float c)
{
    return (c * 9.0f / 5.0f) + 32.0f;
}

float fahrenheitACelsius(float f)
{
    return (f - 32.0f) * 5.0f / 9.0f;
}

// d) FUNCIÓN: Módulo de un vector del plano
float moduloVector2D(float vx, float vy)
{
    return sqrt((vx * vx) + (vy * vy));
}

// e) PROCEDIMIENTO: Suma de dos vectores del plano (devuelve 2 componentes rx y ry)
void sumarVectores2D(float x1, float y1, float x2, float y2, float *rx, float *ry)
{
    *rx = x1 + x2;
    *ry = y1 + y2;
}

// f) FUNCIONES: Conversión entre mayúsculas y minúsculas
char aMinuscula(char letra)
{
    if (letra >= 'A' && letra <= 'Z')
        return letra + ('a' - 'A');
    return letra;
}

char aMayuscula(char letra)
{
    if (letra >= 'a' && letra <= 'z')
        return letra - ('a' - 'A');
    return letra;
}

// g) FUNCIÓN: Cálculo de PI sabiendo que arctan(1) = PI / 4
double calcularPi(void)
{
    return 4.0 * atan(1.0);
}

int main()
{
    float r1 = 0, r2 = 0, sx = 0, sy = 0;
    int compleja = 0;

    // Prueba inciso a: x^2 + 2x + 5 = 0 (raíces complejas: -1 +- 2i)
    raicesCuadratica(1.0f, 2.0f, 5.0f, &r1, &r2, &compleja);
    if (compleja)
        printf("a) Raices complejas: %.2f + %.2fi  y  %.2f - %.2fi\n", r1, r2, r1, r2);
    else
        printf("a) Raices reales: x1 = %.2f, x2 = %.2f\n", r1, r2);

    printf("b) Promedio de (4, 7, 8, 9, 10, 6): %.2f\n", promedio6(4, 7, 8, 9, 10, 6));
    printf("c) 25 C a Fahrenheit: %.2f F | 77 F a Celsius: %.2f C\n",
           celsiusAFahrenheit(25.0f), fahrenheitACelsius(77.0f));
    printf("d) Modulo del vector (3, 4): %.2f\n", moduloVector2D(3.0f, 4.0f));

    sumarVectores2D(2.0f, 5.0f, 4.0f, -1.0f, &sx, &sy);
    printf("e) Suma de vectores (2,5) + (4,-1) = (%.2f, %.2f)\n", sx, sy);

    printf("f) 'G' a minuscula: %c | 'm' a mayuscula: %c\n",
           aMinuscula('G'), aMayuscula('m'));
    printf("g) Valor de PI mediante 4 * atan(1): %.8f\n", calcularPi());

    return 0;
}

Ejercicio 5: Funciones de conversión entre sistemas de numeración

Definir funciones que permitan convertir: a. un número entero binario a base decimal b. un número entero decimal a base 2 c. un número entero en base B a decimal d. un número entero decimal a base B e. un número entero en base B a base C

#include <stdio.h>

// a) Binario a Decimal
long binarioADecimal(long bin)
{
    long decimal = 0, peso = 1;
    while (bin > 0)
    {
        decimal += (bin % 10) * peso;
        bin /= 10;
        peso *= 2;
    }
    return decimal;
}

// b) Decimal a Base 2 (Binario)
long decimalABinario(long dec)
{
    long binario = 0, posicion = 1;
    while (dec > 0)
    {
        binario += (dec % 2) * posicion;
        dec /= 2;
        posicion *= 10;
    }
    return binario;
}

// c) Base B a Decimal (para 2 <= B <= 10)
long baseBADecimal(long num_b, int base_b)
{
    long decimal = 0, peso = 1;
    while (num_b > 0)
    {
        decimal += (num_b % 10) * peso;
        num_b /= 10;
        peso *= base_b;
    }
    return decimal;
}

// d) Decimal a Base B (para 2 <= B <= 10)
long decimalABaseB(long dec, int base_b)
{
    long resultado = 0, posicion = 1;
    while (dec > 0)
    {
        resultado += (dec % base_b) * posicion;
        dec /= base_b;
        posicion *= 10;
    }
    return resultado;
}

// e) Base B a Base C (reutilizando modularmente las funciones c y d)
long baseBABaseC(long num_b, int base_b, int base_c)
{
    long intermedio_decimal = baseBADecimal(num_b, base_b);
    return decimalABaseB(intermedio_decimal, base_c);
}

int main()
{
    long num = 0;
    int b_orig = 0, b_dest = 0;

    printf("a) Binario 101111 a Decimal:       %ld\n", binarioADecimal(101111));
    printf("b) Decimal 47 a Binario:           %ld\n", decimalABinario(47));
    printf("c) Octal (base 8) 57 a Decimal:    %ld\n", baseBADecimal(57, 8));
    printf("d) Decimal 47 a Base 5:            %ld\n", decimalABaseB(47, 5));

    printf("\n--- Prueba Inciso e (Conversion general Base B a Base C) ---\n");
    printf("Ingrese el numero entero en base origen: ");
    scanf("%ld", &num);
    printf("Ingrese la base de origen (2 a 10) y la base destino (2 a 10): ");
    scanf("%d %d", &b_orig, &b_dest);

    printf("El numero %ld (base %d) equivale a %ld (base %d).\n",
           num, b_orig, baseBABaseC(num, b_orig, b_dest), b_dest);

    return 0;
}

Ejercicio 6: Funciones de validación y clasificación

Definir las siguientes funciones: a. signo, que decide si un número es positivo, negativo o cero (devuelve 1, -1, 0 respectivamente) b. esMayus, que decide si una letra dada es mayúscula o no lo es c. esVocal, si una letra dada es vocal o no lo es d. esMultiplo, que decide si el primer parámetro es múltiplo del segundo; ambos parámetros son números enteros

#include <stdio.h>
#include <ctype.h>

// a) Devuelve 1 si es positivo, -1 si es negativo y 0 si es cero
int signo(float num)
{
    if (num > 0) return 1;
    if (num < 0) return -1;
    return 0;
}

// b) Devuelve 1 (verdadero) si es mayúscula, 0 (falso) en caso contrario
int esMayus(char letra)
{
    return (letra >= 'A' && letra <= 'Z') ? 1 : 0;
}

// c) Devuelve 1 (verdadero) si es vocal (mayúscula o minúscula), 0 si no lo es
int esVocal(char letra)
{
    char min = tolower(letra);
    return (min == 'a' || min == 'e' || min == 'i' || min == 'o' || min == 'u') ? 1 : 0;
}

// d) Devuelve 1 si 'a' es múltiplo de 'b', 0 en caso contrario (cuidando b != 0)
int esMultiplo(int a, int b)
{
    if (b == 0) return 0;
    return (a % b == 0) ? 1 : 0;
}

int main()
{
    float n = 0;
    char ch;
    int x = 0, y = 0;

    printf("Ingrese un numero real para evaluar su signo: ");
    scanf("%f", &n);
    printf("-> signo(%.2f) = %d\n\n", n, signo(n));

    printf("Ingrese una letra para evaluar esMayus y esVocal: ");
    scanf(" %c", &ch);
    printf("-> esMayus('%c') = %s\n", ch, esMayus(ch) ? "Verdadero (1)" : "Falso (0)");
    printf("-> esVocal('%c') = %s\n\n", ch, esVocal(ch) ? "Verdadero (1)" : "Falso (0)");

    printf("Ingrese dos numeros enteros para verificar si el 1ro es multiplo del 2do: ");
    scanf("%d %d", &x, &y);
    printf("-> esMultiplo(%d, %d) = %s\n", x, y, esMultiplo(x, y) ? "Verdadero (1)" : "Falso (0)");

    return 0;
}

Ejercicio 7: Simulación de pasaje de parámetros y alcance de variables

Simular 3 ejecuciones distintas del siguiente código, con valores diferentes para las variables G1, G2 y G3. Examinar el código y determinar su salida. Programa Prueba Variables G1, G2, G3: Entero 3 Procedimiento PP (pValor: Entero 3; REF: pRef: Entero 3) Variables L1, L2: Entero 3 Hacer L1 := G2 L2 := pRef pValor := L1 + L2 pRef := L1 - L2 G3 := 10 * L1 Fin Hacer Fin Procedimiento Hacer Leer: G1, G2, G3 Imprimir: 'antes de PP, G1=', G1 Imprimir: 'antes de PP, G2=', G2 Imprimir: 'antes de PP, G3=', G3 PP (G2, G1) Imprimir: 'despues de PP, G1=', G1 Imprimir: 'despues de PP, G2=', G2 Imprimir: 'despues de PP, G3=', G3 Fin Hacer Fin Programa

Análisis del Comportamiento en Memoria:

Al invocar PP(G2, G1), se establece una correspondencia posicional entre los argumentos actuales y los parámetros formales:

  • pValor (recibe G2 por valor/copia): La instrucción pValor := L1 + L2 solo modifica la copia local en el Registro de Activación de PP. Por lo tanto, la variable global G2 nunca cambia su valor ($\text{G2}_{\text{final}} = \text{G2}_{\text{inicial}}$).
  • pRef (recibe la dirección de G1 por referencia): En L2 := pRef se guarda el valor original de G1, y en pRef := L1 - L2 se escribe directamente sobre la celda de memoria de G1 el resultado de $\text{G2}_{\text{inicial}} - \text{G1}_{\text{inicial}}$.
  • G3 (variable global modificada directamente): Como G3 no fue declarada localmente en PP, la asignación G3 := 10 * L1 produce un efecto lateral modificando la variable global G3 al valor $10 \cdot \text{G2}_{\text{inicial}}$, sin importar qué valor tenía G3 antes del llamado.
Simulación Entrada (Antes de PP) Variables Locales en PP Salida (Después de PP)
Ejecución 1 G1 = 4, G2 = 10, G3 = 5 L1 = 10, L2 = 4, pValor = 14 G1 = 6, G2 = 10, G3 = 100
Ejecución 2 G1 = 15, G2 = 5, G3 = 99 L1 = 5, L2 = 15, pValor = 20 G1 = -10, G2 = 5, G3 = 50
Ejecución 3 G1 = -3, G2 = 8, G3 = 0 L1 = 8, L2 = -3, pValor = 5 G1 = 11, G2 = 8, G3 = 80 
#include <stdio.h>

// Variables globales
int G1, G2, G3;

// Procedimiento PP: pValor por copia, pRef por referencia (puntero)
void PP(int pValor, int *pRef)
{
    int L1, L2;

    L1 = G2;
    L2 = *pRef;
    pValor = L1 + L2;
    *pRef = L1 - L2;
    G3 = 10 * L1;
}

int main()
{
    printf("Ingrese los valores iniciales de G1, G2 y G3: ");
    scanf("%d %d %d", &G1, &G2, &G3);

    printf("\nantes de PP, G1 = %d\n", G1);
    printf("antes de PP, G2 = %d\n", G2);
    printf("antes de PP, G3 = %d\n", G3);

    // Invocación: G2 se pasa por valor y G1 se pasa por referencia (&G1)
    PP(G2, &G1);

    printf("\ndespues de PP, G1 = %d\n", G1);
    printf("despues de PP, G2 = %d\n", G2);
    printf("despues de PP, G3 = %d\n", G3);

    return 0;
}

Ejercicio 8: Números naturales primos menores que un número dado

Hacer un programa que imprima todos los números naturales primos menores que un número dado. Recordar que los números naturales primos son los que sólo admiten 2 divisores: 1 y sí mismos, y que los divisores de un número distintos de él mismo son menores que la mitad.

#include <stdio.h>

// Función que determina si un número natural es primo utilizando la propiedad de n/2
int esPrimo(int n)
{
    int d;
    if (n < 2) return 0;

    for (d = 2; d <= n / 2; d++)
    {
        if (n % d == 0)
        {
            return 0; // Encontró un divisor propio: no es primo
        }
    }
    return 1; // Es primo
}

// Procedimiento que imprime todos los primos menores que el límite recibido
void mostrarPrimosMenores(int limite)
{
    int candidato;
    printf("\nNumeros naturales primos menores que %d:\n", limite);

    for (candidato = 2; candidato < limite; candidato++)
    {
        if (esPrimo(candidato))
        {
            printf("%d ", candidato);
        }
    }
    printf("\n");
}

int main()
{
    int numero = 0;

    printf("Ingrese un numero entero positivo: ");
    scanf("%d", &numero);

    if (numero <= 2)
    {
        printf("No existen numeros naturales primos menores que %d.\n", numero);
    }
    else
    {
        mostrarPrimosMenores(numero);
    }

    return 0;
}
